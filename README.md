# KMN AI — مساعد ذكاء اصطناعي لأندرويد

تطبيق دردشة أندرويد حقيقي يتصل بواجهة OpenAI Responses API.

## ما يقدمه
- محادثة نصية تفاعلية.
- حفظ سجل المحادثة محليًا.
- زر محادثة جديدة/مسح المحادثة من الإعدادات.
- اختيار النموذج: GPT-5.6 Luna / Terra / Sol.
- تعليمات شخصية للمساعد.
- واجهة عربية مناسبة للهاتف.
- يعمل عبر الإنترنت عند وجود اتصال.
- لا يضع مفتاح API داخل APK؛ المستخدم يدخله من الإعدادات، ويظل في الذاكرة فقط في هذه النسخة.

## البناء السحابي
ارفع المشروع إلى GitHub ثم:
Actions → Build KMN AI APK → Run workflow

سيظهر الملف داخل Artifacts باسم:
KMN-AI-debug-apk

بعد فك الضغط تجد:
app-debug.apk

## ملاحظة أمان
للنشر العام، الأفضل استخدام خادم وسيط (backend) لحماية مفتاح API بدل وضعه في تطبيق العميل.
